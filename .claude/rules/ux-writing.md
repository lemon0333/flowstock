# UX Writing 규칙 — 토스 보이스톤

사용자 노출 텍스트(버튼/안내/에러/모달/이메일 등) 작성 시 적용. 출처: 토스 [UX Writing 가이드](https://developers-apps-in-toss.toss.im/design/ux-writing.md).

## 1. 해요체 — 모든 문구

상황·맥락 불문 해요체. "~합니다", "~입니다" → "~해요", "~예요".

| ❌ | ✅ |
|---|---|
| 회원 가입이 완료되었습니다 | 회원 가입이 끝났어요 |
| 토큰이 재발급되었습니다 | 새 토큰을 받았어요 |
| 분석 결과를 불러오는 중입니다 | 분석 결과를 불러오고 있어요 |

## 2. 능동적 말하기

수동형(되었-, ~된)은 [예외 케이스](#예외-규칙)만. 나머지는 능동형.

| ❌ | ✅ |
|---|---|
| 거래가 기록되었어요 | 거래를 기록했어요 |
| 권한이 변경되었습니다 | 권한을 바꿨어요 |
| 데이터를 받지 못했습니다 | 데이터를 못 받았어요 |

`~었`도 가능하면 빼기:
- "저장되었어요" → "저장했어요"
- "발송되었습니다" → "보냈어요"

## 3. 긍정적 말하기

"안 돼요/없어요" 대신 "~하면 ~할 수 있어요".

| ❌ | ✅ |
|---|---|
| 보유하지 않은 종목입니다 | 보유 중인 종목만 팔 수 있어요 |
| 잔고가 부족합니다 | 잔고가 모자라요 (또는 "X원이 더 필요해요") |
| 권한이 없습니다 | 관리자만 볼 수 있어요 |
| AI 응답이 비어있어요 | 다시 시도해 볼게요 |

**다이얼로그 왼쪽 버튼 = "닫기"** ("취소"는 작업 자체가 취소됐다고 오해). confirm 다이얼로그도 마찬가지.

## 4. 캐주얼한 경어 — 과도한 경어 금지

`~시겠어요?`, `~시나요?`, `~께`, `여쭈다`, `계시다` 안 씀.

| ❌ | ✅ |
|---|---|
| 정말 초기화 하시겠습니까? | 모두 초기화할까요? |
| 삭제하시겠어요? | 삭제할까요? |
| 어디에 계신가요? | 어디 있어요? |
| 사장님께 보냈어요 | 사장님에게 보냈어요 |
| 여쭤볼게요 | 확인해 볼게요 |

`~시` 빼기:
- "확인해 보세요" → "확인해요"
- "선택하세요" → "골라요" 또는 "선택해요"

질문에서 `~시` 빼면 어색하면 → 정보 자체를 주어로:
- "이름이 어떻게 되시나요?" → "이름이 뭐예요?"

## 5. 명사 + 명사 안 쓰기 / 한자어 풀어쓰기

| ❌ | ✅ |
|---|---|
| 신청 완료 | 신청을 끝냈어요 |
| 거래 기록 등록 실패 | 거래를 기록하지 못했어요 |
| 권한 변경 완료 | 권한을 바꿨어요 |

## 6. 버튼 카피

- 1인칭/명령형 X. 단답형 동사 OK: "삭제", "저장", "공개로 전환".
- "확인" 단독은 모호 → 의미 있는 동사 ("저장", "공개로 전환").
- 다이얼로그 왼쪽 = **"닫기"** (항상). 오른쪽 = 핵심 동작.
- 비활성 상태 안내는 버튼 옆 작은 텍스트 ("3종목 이상 골라야 비교할 수 있어요").

## 7. 에러 / 빈 상태

- 에러: 무엇이 / 어떻게 → 사용자가 다음에 할 행동까지.
  - ❌ "오류가 발생했습니다."
  - ✅ "잠깐 연결이 끊겼어요. 새로고침해 볼게요."
- 빈 상태: 다음 행동 유도.
  - ❌ "데이터가 없습니다."
  - ✅ "아직 공개된 거래가 없어요. 첫 번째 랭커가 되어보세요."

## 예외 규칙 — 수동형 OK인 경우

- 시스템 장애 시 책임 분산: "일시적으로 처리되지 않았어요" (사용자 잘못 아닌 걸 강조)
- 법적 표현: "약관이 변경되었어요" (변경의 주체가 회사임이 명확)

## 적용 체크리스트

PR/commit에서 사용자 노출 텍스트 추가/수정 시 확인:

- [ ] 모든 문장이 해요체인가
- [ ] 수동형(되었-, ~된)을 능동형으로 바꿀 수 있는가
- [ ] "안 돼요/없어요" 대신 "~할 수 있어요" 쓸 수 있는가
- [ ] `~시겠`/`~시나` 패턴 없는가
- [ ] 다이얼로그 왼쪽 버튼이 "취소" 대신 "닫기"인가
- [ ] 한자어 명사 나열을 동사로 풀 수 있는가
- [ ] 에러는 다음 행동까지 안내하는가
